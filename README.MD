# 🍕 FoodExpress - Restoran Telegram Bot

FoodExpress - bu Telegram bot va Web App orqali ishlaydigan to'liq funksiyali restoran yetkazib berish tizimi.

---

## 🚀 **Asosiy xususiyatlar**

### 👤 Foydalanuvchi uchun:
- 🔐 Ro'yxatdan o'tish / Tizimga kirish
- 🍽 Menyuni ko'rish (kategoriyalar bo'yicha)
- 🛒 Savat va buyurtma berish
- 📍 Yetkazish manzilini aniqlash
- 💳 To'lov usullari (Naqd, Click, Payme)
- 📋 Buyurtma tarixi
- 🎁 Bonus tizimi (5%)

### 🔐 Admin uchun:
- 📊 Dashboard statistika
- 📋 Buyurtmalarni boshqarish
- 🍽 Menyu boshqaruvi
- 👥 Foydalanuvchilar ro'yxati
- 📢 Xabar yuborish
- ⚙️ Sozlamalar
